# Travik01

Разработчица и исследовательница: прикладное машинное обучение, компьютерное зрение, молекулярная динамика, геоданные и автоматизация на Python. Умею собирать сайты целиком — фронтенд и бэкенд, от интерфейса до серверной части и кэширования. Активно работаю с внешними API и ключами доступа (секреты храню вне репозитория), встраиваю ИИ-агентов в проекты.

**Стек:** Python · JavaScript · Flask · фронтенд и бэкенд веб-приложений · внешние API и API-ключи · интеграция ИИ-агентов · CNN и классические ML-модели · Telegram-боты · OpenStreetMap · OpenMM / MDTraj / RDKit.

**Проекты**

- [Rreta](https://github.com/Travik01/Rreta) — пайплайн молекулярной динамики белок–лиганд: структура, докинг, симуляция и анализ траекторий.
- [Panorama-OSM-Backend-Backend-3D--POI](https://github.com/Travik01/Panorama-OSM-Backend-Backend-3D--POI) — бэкенд для панорам и данных OpenStreetMap с двухуровневым кэшированием и подготовкой к 3D-визуализации.
- [ASL-Sign-Language-Detector-CNN-Classifier](https://github.com/Travik01/ASL-Sign-Language-Detector-CNN-Classifier) — CNN-классификатор жестов ASL на 35 классов с обучением, метриками и экспортом модели.
- [Loan-Approval-Predictor-Bot](https://github.com/Travik01/Loan-Approval-Predictor-Bot) — Telegram-бот с LDA-моделью предсказания одобрения кредита.
- [Automated-textile-materials-analysis-system-for-space-conditions](https://github.com/Travik01/Automated-textile-materials-analysis-system-for-space-conditions) — система анализа текстильных материалов для космических и авиационных условий.
